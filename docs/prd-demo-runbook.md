# Prism 演示 Runbook（8-12 分钟）

## 1. 演示目标
在单设备 Web 端完整展示“学习闭环 + 六模块联动 + 故障可降级”，确保评审方看到可落地性而非单点能力。

## 2. 演示前检查清单（T-30 分钟）
1. 环境变量可用：`NEXT_PUBLIC_API_BASE_URL`、Supabase、AI Provider Key。
2. 三服务健康检查通过：
- Web：`http://localhost:3000`
- Server：`http://localhost:8080/health`
- AI：`http://localhost:5000/health`
3. 预置账号可登录，且存在数学/物理样例数据。
4. 摄像头与麦克风权限已授权（若演示监测流）。

## 3. 演示脚本（建议 10 分钟）
## 3.1 第 0-1 分钟：开场与目标
- 讲解词：
  - “Prism 面向高中生自习场景，核心是因材施教与学习健康并重。”
  - “今天演示完整学习闭环，不只展示单个 AI 能力点。”

## 3.2 第 1-3 分钟：冷启动测评与路径生成（模块1）
1. 进入测评页面，创建会话：选择学科 `math`，设置目标知识点与目标日期。
2. 快速提交样例答案。
3. 展示返回结果：薄弱点列表 + 学习路径图（节点状态、依赖边、当前节点）。
- 讲解词：
  - “路径不是静态推荐，后续练习会实时调整。”

## 3.3 第 3-4.5 分钟：作业上传与批改反馈（模块1联动模块4）
1. 上传预置作业图片。
2. 展示 OCR 文本与分题批改结果。
3. 指出薄弱点如何反向影响路径优先级。

## 3.4 第 4.5-6 分钟：虚拟助教分层答疑（模块3）
1. 在助教面板提问当前薄弱知识点问题。
2. 展示“提示 -> 解释 -> 结论”的分层输出。
3. 展示关联知识点回链能力。
- 讲解词：
  - “默认先引导思路，避免直接给答案导致被动学习。”

## 3.5 第 6-7.5 分钟：智能笔记沉淀与检索（模块4）
1. 把作业 OCR 结果或语音转写结果保存为笔记。
2. 展示结构化摘要和知识点关联。
3. 输入语义查询，展示命中笔记。

## 3.6 第 7.5-8.5 分钟：健康提醒与轻干预（模块2+5）
1. 展示监测面板状态变化（专注度/疲劳/坐姿）。
2. 展示系统返回轻干预建议（如休息建议、姿态提醒）。
- 讲解词：
  - “我们不强制打断学习流程，优先轻干预。”

## 3.7 第 8.5-9.5 分钟：场景切换（模块6）
1. 从 `self-study` 切换到 `exam-prep`。
2. 展示策略模板变化（路径模式、助教模式、干预强度）。
3. 证明路径与会话数据连续。

## 3.8 第 9.5-10 分钟：收束
- 讲解词：
  - “六模块已形成闭环，并通过统一接口与降级策略保障演示稳定。”

## 4. 关键演示证据点
1. 路径数据动态变化（非静态页面）。
2. 助教流式响应（非一次性答案）。
3. 笔记可检索且与知识点绑定。
4. 干预可触发且不阻断主流程。
5. 场景切换可即时生效。

## 5. 故障降级手册
## 5.1 AI 超时或失败
- 现象：批改/助教响应长时间等待。
- 操作：切换到预置回退模式，展示静态建议与历史结果。
- 台词：
  - “当前上游模型响应超时，系统已自动回退到稳定策略，主流程继续。”

## 5.2 WebSocket 中断
- 现象：监测或助教流停止。
- 操作：触发重连按钮，加载最近会话缓存。
- 台词：
  - “网络抖动时会自动重连并恢复上下文，不需要重开会话。”

## 5.3 OCR/转写失败
- 现象：笔记生成失败。
- 操作：切换到预置样例输入，继续检索演示。
- 台词：
  - “输入处理失败会保留原始材料并允许重试，不影响学习链路。”

## 5.4 鉴权失效
- 现象：接口返回 `401`。
- 操作：重新登录并恢复会话。
- 台词：
  - “系统使用本地 JWT 校验，鉴权失效会立即阻断未授权访问。”

## 6. 演示角色分工建议
1. 主讲：流程推进与价值阐述。
2. 操作手：页面点击、输入与故障切换。
3. 备援讲解：当故障触发时解释降级机制。

## 7. 演示后 Q&A 备答锚点
1. 为什么不先做教师端：首版聚焦学生闭环，减少风险。
2. 为什么不用强干预：优先学习连续性与用户接受度。
3. 如何保证可扩展：模块化 API + 统一 WS 协议 + 分期路线。
